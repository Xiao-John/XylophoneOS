# Pumpkin P1 客体测试守护进程

[P0 身份契约](pumpkin_identity.md) 的核心通过现有 sys84–86 端点运行。原生构建输出
`pumpkind.elf` 和 `pumpkin_probe.elf`。守护进程只接受显式 `--volatile-test` 启动，
每次使用新安装域和内存账户库，仅发布测试名称 `pumpkin-p1-test`。正式包、登录入口和
持久化配置待实现。

## 启动和端点权利

1. 受信启动器先发布私用会合名称，然后创建守护进程，保留实际创建所得的进程绑定。
   守护进程以 `sys84 create(peer=0)` 让内核将控制端点配对到真正的父进程。
2. 守护进程连接启动器的会合名称，核验会合端点的双方方向都匹配控制端点的内核对端。
   启动器也检查会合端点属于实际启动的守护进程。双方再交换控制端点编号与新安装域。
   守护进程观察引介消息已被读取后关闭会合端点。
3. 守护进程只在先前配对的专用端点接纳登记角色。普通客户端在命名端点接纳，角色固定
   为普通客户端。名称只用于发现，客户端还需核验两方向均绑定到受信启动器给定的服务
   对端。拥有同一 PID 的其它连接也无法取得登记权限或复用会话。
4. 服务端用自己保存的连接标识调用 P0 核心。对端失效、协议错误和连接到期都回收
   传输与会话。当前启动器拥有整个测试生命周期，专用控制端断开即停止守护进程。
   送端就绪检测同样检查对端仍存在。接纳每轮至多四个，单连接每轮至多一条请求。

时钟从 sys46 读取，使用 sys47 进行有界轮询。熵通过 sys63 获取，失败终止启动或令创建、
轮换明确失败。P1 API 保留 `store_api` 注入点，客体内存适配器仅供验证 IPC 和生命周期。

## 私有消息

操作号、错误号和线格式仅用于这一测试候选。正式 SDK 消息需按 ABI 协作流程单独冻结。
多字节字段为 little-endian，结构和尺寸见 `src/user/pumpkin/daemon_protocol.hpp`。

- 请求固定 120 字节，包含版本、操作、每连接从 1 严格递增的序号、单调期限、会话或
  账户 ID、名称长度、保留字段、零填充名称和 32 字节凭据缓冲。非适用字段全零。
- 响应固定 80 字节，回传版本、操作和序号，包含状态、标志、可选 ID 和凭据。
  只有登记创建和轮换的成功响应携带凭据。失败响应的附加字段全零。
- 支持认证、注销、读取当前会话身份、创建、查询、轮换和吊销。文件权限和所有者
  记录仍由有对象授权的受信资源服务提供。
- 未知版本、非法帧和重放导致断开。处理前用当前单调时钟复查请求期限，最大间隔五秒。
  超时响应表示操作未执行。单槽响应须在有限窗口内读走，预算 500 毫秒。
- 已确认送出但收不到合法响应时，客户端返回结果未知并关闭连接。客户端仅将发送前
  失败报告为未送出，任何一类失败均由调用方决定后续动作。服务遇到持久发布结果未知
  时尝试送出对应状态并进入排空阶段，拒绝后续工作。恢复时用登记查询核对版本与账户。

## 部署依赖

真实磁盘后端须有服务私有访问权、可验证的原子提交点与同步语义，以及针对旧账户库的
防回滚机制。现有 FAT 投影、可写路径和粗粒度整盘能力不能提供这些属性。磁盘验证需
覆盖提交前后断电、满盘、损坏和多写者冲突。正式发布还须审计内核 IPC 邮箱和诊断
缓冲中的凭据驻留时间，当前适配器只直接擦除用户态工作缓冲。正式登录凭据采集、
控制端重授、文件用户归属和 Mobius 验收各自推进。
