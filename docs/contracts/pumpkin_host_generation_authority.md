# Pumpkin 开发配置的独立代际记录

[`pumpkin_generation_authority.py`](../../scripts/pumpkin_generation_authority.py) 是显式开发配置的宿主组件。监督器选择一个已持久建立的私有宿主根目录。同一配置的进程从同一个根目录和安装域打开记录。安装域的十六进制值唯一确定该根目录中的子目录。根目录及安装域目录均由宿主监督器的身份拥有，客体镜像、虚机快照、共享目录和恢复脚本的工作范围不含该目录。宿主目录具有可信上级路径，监督器在运行时保留目录及路径绑定。

## 初始化与发布

`provision()` 只为显式选定的新安装域创建目录，同步父目录，并写入带安装域及完整性校验的空记录。它拒绝已有目录。启动调用 `read()`，仅完整空记录返回 `None`。已配置域的目录、文件或记录缺失和损坏均报错。监督器持有首次配置授权。重启和备份恢复不调用 `provision()`。

`publish(expected, next_mark)` 比较安装域、修订号、快照长度及 P0 快照的 SHA-256 摘要。候选修订必须正好比预期修订大一，首次修订为 1，达到 u64 上限后停止。长度匹配 P0 快照的记录边界，空状态用 `None` 表示。格式不合法或修订推进无效时抛出 `ValueError`。多个宿主进程用同一目录 inode 的 `flock` 串行完成比较及发布，替换数据记录期间锁仍有效。读者在共享锁内验证。

记录为 100 字节，包含 8 字节版本标识、16 字节安装域、u64 修订、u32 快照长度、32 字节快照摘要和 32 字节记录校验值。整数为 little-endian。空记录的修订、长度和摘要均为零。文件是当前宿主身份拥有的私有普通文件。记录校验检测损坏，访问由私有目录保护。宿主锁只串行化记录读写。客体仍需要现行 files 独占租约保护整个快照操作。

发布先写入并同步同目录 `pending`，原子替换 `generation`，同步目录，最后重新读取完整记录。成功回读返回 `committed`。验证后的当前记录与预期不同返回 `conflict`。仅暂存失败且确认活动记录完整如前时返回 `unchanged`。其余 I/O、内容校验及提交边界失败返回 `outcome_unknown`。重启只读 `generation`。进程在替换前退出时，暂存记录由下次写入清理。若已替换，新进程在同一目录锁内先验证当前记录并同步目录，然后返回记录。回复丢失后用读取确认提交状态。

## 后续客体接入

显式测试监督器创建一次性工作盘及盘外宿主根目录，固定安装域、启动实例和唯一能使用代际记录的 Pumpkin 席位。在读记录、写槽、同步、读回和发布期间保留现有 files 租约。全配置同时只允许一个客体写者。通过未来受保护的专用通道接到 `publication_io` 的 `read_generation` 和 `publish_generation`。`None` 映射到已知空库，`generation_error` 映射到读取错误，四类发布结果逐一传递。通道交付后丢失回复按结果未知停止服务。客体用 `snapshot_publication` 选择精确槽位并检查完整摘要。

集成验证应固定源代码、系统和 profile 标识，使用一次性镜像。提交并吊销真实测试账户后，只恢复旧镜像，保留并重新打开宿主记录，启动及认证须拒绝旧槽。还应覆盖相同修订但不同摘要、当前槽损坏或缺失、宿主记录缺失、回复丢失和正常重启。测试密钥继续走现有私有凭据路径。

[宿主实测](../work_log/cd9e44fb_pumpkin_independent_host_generation_authority.md) 在真实 APFS 上验证宿主进程中断与重启，以及仅替换独立宿主快照字节时记录保持。物理断电、整机重启、其他宿主文件系统和真实客体通道仍待验证。能恢复整个宿主目录的管理者处于本开发配置的信任范围内。生产硬件资格独立推进。
