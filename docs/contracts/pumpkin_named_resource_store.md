# Pumpkin 私有具名资源存储

显式 `--pumpkin-anchored-probe --pumpkin-named-resource-store` 使用专用开发安装。
继承真实 files 启动授予、独占双槽租约、写入同步和读回、以及工作盘外受保护的
代际发布。此配置需要新建状态。标准安装和原账户快照格式保持可独立使用。额外启用
`--pumpkin-native-login --pumpkin-user-login --pumpkin-user-resource` 可通过持久账户
和独立 broker 读取同一格式的对象。 [操作者入口](pumpkin_user_login.md)
[files 私用租约](pumpkin_files_client_probe.md) · [盘外代际](pumpkin_anchored_guest.md)

## 快照与更新

每个已发布封套包含原账户快照和一个逻辑具名对象。有效内容最多 4576 字节，适配
现有 4608 字节 files 槽及 16 字节帧头，保留原 64 条账户容量。

| 区段 | 内容 |
| --- | --- |
| 24 字节封套头 | `PUMNAME1`，外层 u64 修订，内层 u32 字节长度，四字节保留 |
| 原账户快照 | 原 P0 格式及校验 |
| 88 字节对象 | u64 对象代际，u64 所有者账户序号，逻辑名和数据长度各一字节，六字节保留，最多各 32 字节的名与数据 |
| 32 字节尾 | 上面整个封套的 SHA-256 |

字段为 little-endian，保留和填充字节全零。空对象区段全零。恢复时同时核对外层
修订、完整账户库、对象的安装域及有效账户编号、对象代际、长度、保留字节和摘要。
所有者完整身份由已选定的安装域和账户编号组成。已吊销账户的所有者记录可保留，
活动会话检查决定其读取权。

原账户核心继续比较内层账户修订。每次账户或资源写入均推进外层修订，只有在独占
租约已同步并校验新槽、独立服务已比较并发布完整新标记后才更新记忆状态。已知
没有发布时继续使用旧状态。发布冲突或结果未知时停止提供资源和账户服务，等待从确切
已发布标记恢复。独立宿主文件采用本配置专用的 `PUMGEN` 格式 2，串口帧尺寸不变。

## 名称与读取

逻辑名用于在私用注册域定位对象，由 1 到 16 个 ASCII 字符组成，首字符为小写字母
或数字，后续字符可使用小写字母、数字、点、下划线和连字符。申请者来自内核核验的普通 Pumpkin 端点，提交
活动会话和可选的预期代际，由服务核对完整所有者及当前对象键。写入与删除只接受
经过真实父方启动授予的独立登记端。初次发布要求对象为空，同名替换和删除都要求
准确的旧代际。每个新对象使用提交时的外层修订作为从不复用的对象编号和代际。
删除后同一个名字重新建对象也获得新键。名字、UID、普通 FAT 路径、目录项、
假定相同的 inode 都不能授权。

四次启动的客体测试以私用操作 12、13、14 验证发布、只读和删除。封套可存最多
32 字节。当前开发入口使用四字节读写载荷。专用四次启动的只读入口直接向
daemon 提交原生会话，在组合登录配置中该入口拒绝，读取由独立 broker 交付。
对象数据、所有者和代际从同一封套原子恢复。命名 FAT 文件归属、物理独立 NV、
掉电和控台资格仍待专项验收。

## 四次启动

此序列使用独立具名存储配置。组合登录配置的受信代际代理只接受登录操作或具名
broker 操作，四次启动的场景编号会在转交监督程序前被拒绝。

1. `cycle` 建立两个原生账户。先登记 Alice 所有的对象，在修订 4 暂停宿主 VM
   并保留旧盘。随后同名替换为 Carol 所有的新对象与内容，验证旧键与跨账户拒绝。
2. `healthy` 启动新 VM，恢复替换后准确的对象键、内容和归属。真实登记端轮换
   测试凭据，以两条普通会话核对拒绝与接受。下一步持久删除。
3. `empty` 在新 VM 核对删除保留。有效普通会话不能读旧对象，旧删除请求冲突。
4. `stale` 仅恢复修订 4 的旧工作盘，保留宿主已发布的新标记。真实 daemon
   拒绝启动，旧盘跨本次失败启动保持相同，未发布新代际。
