# 独占字节流读取权：W1 实施契约

2026-10-30。C28 迁移期间 sys80 的 claim 返回 unsupported，不能启用读取权；原内核
console IRQ 等待已撤回。下文是用户态驱动接入后的目标契约，不是当前功能。
既有 console 路由授予所有继承者读取，
现有 IPC 为 files/display 专用端点，均不能表达可信单一读取者或终端服务重启。
本机制只管理受控字节流的读取权，不解释终端模式、转义序列或应用名称；用户态
终端服务负责终端策略。首个设备限定为继承的串口标准输入；不承诺任意设备路径。

拟用 sys80 `sys_stream_lease(fd,action,target)`。调用者由内核当前进程认证，fd 必须
为自身有效、可读的受控设备 route；不得依据名字或自报 PID 获权。action：

- `claim`：只允许真实启动 supervisor，target=0；首次激活时成为根持有者，重复
  返回状态错误。激活前维持既有兼容读取及 Escape 取消；激活后所有直通读取和显式
  等待均检查当前持有者，旧持有者或后台读者返回 denied。
- `delegate`：仅当前持有者，target 必须为内核验证的直接受控子进程，拥有有效同一
  设备可读 route 且非 dead/free/replacement；可以是 building/fresh/running。原子
  入栈，最多 8 层，目标不能重复；旧持有者的等待被唤醒并返回 denied。进程身份
  为内核单调 PID，不以可回收槽位授权。
- `reclaim`：调用者须为委派链中的祖先且 target=0；撤销其全部后代，唤醒失权者。
  当前持有者可主动退回前一层；根持有者无父级时返回状态错误。调用者自身是持有者
  且有父级时退回一层；祖先请求时由祖先接回。权限不能由非链成员夺取。
- `query`：target=0，仅链成员可读当前持有者 PID；不授予新权限。参数、主体、route
  及生命周期错误返回真实失败。全部动作在单核不可抢占内核区间进行。

持有者退出、故障或被杀时从链中移除其本身及后代并唤醒失权等待者；仍存活的最近
祖先恢复权利。根消失时保留激活但无持有者的失效状态，拒绝所有读取，避免重新开放
旧直通；恢复策略另行设计。成功 exec 保留 PID 与权利，失败 exec 不改变；关闭自身
console stdin，或由受控父进程将已委派子进程的 stdin 重定向至非 console，撤销该
进程及其后代的权利。关闭根的输入同样进入失效状态。fork 默认
不自动委派，子进程先被拒绝直到父进程显式委派。队列字节在委派期间保留；丢弃、
模式、回显、前台切换和报错由用户态协议规定。激活后禁用旧的内核 Escape 抢读，
不是信号实现；救援和故障恢复须另外提供并验证。

此机制不承诺后台作业、PTY、termios、任意句柄传递或跨进程多源等待。实现前登记
编号，实施时同步共享头、内核分发、SDK 和 manifest；测试正向委派、拒绝、父子认证、
上限、重复、exec/fork、退出/故障、失效等待、IRQ/超时及资源恢复。全部相关改动提交
后才做客体验收。旧系统与 ABI 资料不得改绑。
