- SDK v5：`.cache/xos_seed/sdk_snapshots/3a302b5cd7e1cdab0f594b0d16d7ca92b753fec7b2efcc6347b01e5a69542edd`
  （manifest SHA256 同目录名）。
- C Seed 派生：`.cache/xos_seed/gcc/relinks/open_capacity_fix/seed_manifest.json`；
  使用 0007 lrealpath 修复，不能直接用原始 `src/ports/gcc/seed_manifest.json`。
- G++ 派生：`.cache/xos_seed/gcc/relinks/gxx_lrealpath_v5/seed_manifest.json`。
- 目标 C++ runtime：`.cache/xos_seed/gcc/relinks/target_runtime_v5_receipt/`
  （v5 口径，已去掉与 libc TLS 入口重复的 GNU atexit 回退成员）。
- 组合安装清单：`build/cpp_bundle/seed_manifest.json` 与
  `build/cpp_bundle/sysroot_manifest.json`，只生成白名单，不自动写日常盘。
- 构建/安装入口在 `scripts/prepare_gcc_seed.py`、`scripts/derive_cpp_runtime.py`、
  `scripts/relink_gcc_seed.py`；原始输入与旧 Seed 不覆盖。

安装要点：

- 工具：`/usr/bin/x86_64-elf-gcc`、`x86_64-elf-g++`、`cpp`；
  `/usr/libexec/gcc/x86_64-elf/16.2.0/{cc1,cc1plus,collect2}`。
- 目标库/头：`/sysroot`（C 头、`cxx_include/<index>`、libc/libm/libxos/libgcc）；
  固定 `/sysroot` 直接 GNU ld profile，不宣称任意位置重定位。
- 普通 C 用直接 GNU ld profile；`collect2` 未验收，不用于当前正式 profile。
- 编译驱动需要 `exec-driver` 的直接子构造权；普通 `exec-file` 不授予。

客体示例：

```text
exec-driver /usr/bin/x86_64-elf-gcc --sysroot=/sysroot -I/src -c /src/main.c -o /out/main.o
exec-driver /usr/bin/x86_64-elf-gcc -static --sysroot=/sysroot /out/main.o -o /out/app.elf
exec-file /out/app.elf

exec-driver /usr/bin/x86_64-elf-g++ -std=gnu++17 -static --sysroot=/sysroot -I/src -c /src/main.cpp -o /out/main.o
exec-driver /usr/bin/x86_64-elf-g++ -static --sysroot=/sysroot /out/main.o -o /out/app.elf
exec-file /out/app.elf
```

## 限制

- 只覆盖受限静态配置；不声称完整 POSIX、完整 C++ 标准库、动态链接、
  LTO/插件、任意 `-pipe`、动态 TLS/DTV/DSO 卸载、线程并发、编译器自举、
  系统重建或任意掉电。
- 512 MiB 单核 TCG；8 任务、65536 页/任务、每会话 16 打开、32 全局 FatFs 锁。
- 目标 TLS 为静态 local-exec、单线程；`iostream` 非本轮必需。
- 真实内存/磁盘高水位、长 soak、R4 并发和最终镜像上的旧全量回归未由本页
  声称；后续压力另列。
- GNU/GCC/libstdc++ 保留原许可与运行库例外；逐成员/公开源码分发审计未完成，
  不以本页替代法律审查。
