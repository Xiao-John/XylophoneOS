## 形成的关键合同

- 内核只做受保护 bootstrap 服务；files/supervisor 与普通用户任务隔离。
- SDK 目标 `x86_64-elf`；用户地址窗口、W^X、栈/启动页预算和 65536 页/任务上限
  在 E04/E08 逐步固定。
- 文件 ABI 使用 4096 字节消息、255 字节 ASCII 路径、每会话打开/全局锁上限；
  FatFs 在 ring3，保存有 staging/journal/backup，正常同步重启可恢复。
- 串口/终端按空格分词；argv 64 项、每项 255 字节；没有引号、完整 POSIX、
  动态链接、SMP 或任意掉电保证。
