## 分期与依赖

| 阶段 | 目标/依赖 | 必须观察到的验收行为 |
|---|---|---|
| PX0 契约 | 本文、子集契约、当前证据入口 | 已有能力与缺口分开；文档链接/阶段状态一致；不新增合规声明 |
| PX1 信号基础 | 进程/线程身份与等待；先定用户现场、进程/线程定向及掩码契约 | sigaction/raise/kill/pthread_sigmask等逐项清单；默认/忽略/处理、待决与屏蔽、线程选择、处理后恢复；SIGKILL/SIGSTOP不可捕获；子进程退出与wait、EINTR/重启、SIGPIPE；不能误伤新复用PID |
| PX2 终端与作业 | PX1；先定session/pgrp、控制终端与服务权限 | termios规范/非规范输入、回显；前后台进程组；Ctrl-C/Ctrl-Z、停止/继续、TTY恢复；dash后台、wait/trap/jobs按各自语义开放，xsh仍可救援 |
| PX3 就绪等待 | 先文件/管道/终端对象；基础部分可先于PX1，原子掩码等待依赖PX1 | poll/select逐接口语义；read/write/hangup/error、超时、空集合、dup/close并发；无丢唤醒和空闲忙轮询；pselect原子信号掩码与等待另验 |
| PX4-A 匿名VM | 独立于PX1/2；先冻结VMA与现有wait_word映射生命期关系 | 匿名私有mmap、munmap、mprotect目标子集；对齐/溢出/地址选择/零页、部分拆分与合并、保护异常、ENOMEM回滚；其他进程隔离、线程并发与退出回收 |
| PX4-B 文件/共享VM | PX4-A，且文件对象/后端一致性契约明确 | 文件映射偏移/长度/尾页、MAP_PRIVATE与MAP_SHARED、fork继承、msync/关闭/截断/越EOF行为；共享可见性与持久化分别验证；不承诺任意断电安全 |
| PX4-C COW优化 | 可选；PX4-A且fork回归基线可用 | 写故障分离、引用计数、退出/exec/共享映射、部分分配失败；内容与eager-copy等价，另记内存和耗时；不作为POSIX合规门槛 |
| PX5 文件语义 | 先文件服务对象与元数据方案；可与PX1/4并行 | UID/GID与mode/umask、时间戳、路径、链接、打开后删除/rename原子可见性及错误；权限绕过拒绝、重启元数据一致性；FAT无法承载的语义先明确后端/元数据方案 |
| PX6 线程/时间补齐 | 复用T系列/PY3 B2，不重复建设墙钟 | 逐项补timed mutex、rwlock、取消/清理、atfork与多线程fork/exec；实时时钟/CPU时间按范围验；默认cond时钟、墙钟跳变与单调超时区分 |
| PX7 工具/locale | 按命令依赖选择PX1/3/5/6；不等待所有能力完成 | 逐工具标准选项、输出、退出状态、错误；Make增量时间戳与所需标准规则；C/POSIX locale、字符处理/模式匹配/路径分别验证 |
| PX8 网络与其余IPC | 独立专项设计；复用PX3，网络设备/协议栈另列依赖 | socket族地址域与连接/半关闭/错误/超时；本地域与TCP/IP分别验；命名共享内存/sem/MQ按所选标准项独立gate |
| PX9 合规收口 | 所有拟声明的基础/选项逐项审计 | 无遗漏的标准清单、限额/能力查询、偏差表和独立测试；是否申请认证另决策，不能以本文建立推定已承诺完整合规 |

每行是阶段范围，不能一次实现几个函数便标整行通过。大行开工时再拆小gate；例如PX6的
线程取消与多线程fork分别实施，不让所有消费者等待同一巨型改造。标准选项取舍以逐项
审计为准，阶段顺序不代表标准中的强制/可选分类。

## 建议接续方式

- 终端体验线：PX1→PX2；dash仅在底层gate通过后开放相应语法/内建，不用Shell假信号代替。
- 内存线：建议主端先设计PX4-A，冻结后实现；PX4-B随后，COW按收益决定。不预派代理。
- 通用服务线：PX3与PX5按实际负责人拆解，为QtCore事件分发和移植减少专用补丁。
- PY3 B2墙钟/时区已由0058收口，PX6复用其实际证据；SQLite/压缩不属于POSIX验收。
- Qt、CPython、xypm只依赖其实际需要的子集；完整POSIX不是它们开工的前置大门。

以上是建议排程，不自动占用他人文件。开始代码任务前在state登记负责人、文件、ABI和
构建目录；共享build排他。文件系统元数据/安全主体与网络是独立工程，不能以兼容包装
绕过微内核权限与生命周期设计。

## 第一批具体交付：PX4-A设计包（提案已启动，未实施）

1. 查清现有页分配、用户映射、fork/exec回滚、线程wait_word与装载器的真实调用路径。
2. 定义VMA对象/范围分裂合并、权限/所有权、配额、地址选择、锁顺序及映射撤销协议；
   尤其复核线程契约中有等待者时busy拒绝解除映射的选择，不能直接把该限制冒称完整munmap。
3. 冻结匿名映射子集、错误表与ABI/SDK特征协商。先不引入文件映射、共享内存命名或COW。
4. 建立独立guest探针：零页与读写、保护故障隔离、部分unmap与地址复用、溢出/无效请求、
   资源耗尽回滚、线程冲突与退出回收。只回归受影响的fork/exec/线程/装载路径。

具体wire、地址图、限额、失败/等待生命周期和V1–V7验收见[匿名VM提案](../contracts/anonymous_vm.md)。
