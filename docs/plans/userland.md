# 用户态工具候选与实施入口

2026-10-27。P类菜单，不是强制排期；开工时再核当前底座和实际版本/许可证。
旧勘查中的“无线程/无fork/无墙钟”不再作为当前能力判断，现状见../state.md。

| 方向 | 当前/下一项 | 所需契约 |
|---|---|---|
| Shell与基础工具 | xsh/dash C3、部分sbase和受限Make已有证据；增量构建/文本工具可继续 | Shell/Make实现说明、POSIX PX7 |
| 编辑与文本 | 小型编辑器、grep/sed/awk、diff等按实际缺口挑选 | 文件/错误、终端/信号、locale与正则分别核对 |
| Python与游戏 | CPython B段已验；Open Adventure有原生构建，完整游戏流程未验 | CPython/游戏专项，避免软件内部伪造底座 |
| GUI | QtCore→QPA/Widgets，QML→Quick独立模块线；SDL次选 | Qt协作契约，线程/等待/显示/内存实际依赖 |
| 开发工具 | NASM/CMake/生成器、Clang/LLVM、调试工具按系统重建/移植需要扩展 | 固定执行地与目标、SDK/运行库/构建依赖 |
| 网络应用/完整桌面 | 暂不作为首窗或当前发行前置 | socket/TLS/安全与资源体系先专项建设 |

选择标准：改善实际开发/玩耍、复用现有能力、暴露可复用缺口、能形成独立客体gate。
同一需求先补公共接口，避免为每个工具增加内核程序名特判；第三方来源/版本/补丁/许可
在动代码时固定。候选清单不是上游可用性或兼容性证明，不以静态菜单代替实时勘查。

日常工具优先按[DU设计](daily_utilities.md)统一命令支持面、来源、SDK/profile、安装清单
和客体gate；首批文件/文本工具不以完整POSIX或新Shell为前置，本轮仅设计。
