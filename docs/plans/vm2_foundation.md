# VM2 基底实施

2026-11-09。状态：基底受限实现并定向验收；VM2的页面操作尚未实现。以 VM1 探针为基线，先交付不开放公共 VM 的机制：

1. 定义每进程独占的可取消、分批内核事务状态与发布边界；固定工作预算，
   事务状态不得依赖中断帧以外的内核栈局部变量。
2. 在调度路径增加可恢复的有界续体，确保同进程其他用户线程不能观察中间状态，
   其他进程和统一时钟继续前进；退出/kill按发布前后分别撤回或完成。
3. 覆盖等待 word、process/join 输出及其他异步缓冲的 pin 生命周期；按真实线程
   并发和取消验证，不用重复的可读性检查冒充pin。
4. 专用镜像进行批次、公平性、取消、时钟、pin和资源回收验收；默认镜像不暴露
   探针。全部通过后再接入VM2的PTE事务，保留commit/protect等接口尚未实现的状态。

详细行为、V2/V4/V5和资源限制以[匿名VM契约](../contracts/anonymous_vm.md)为准。

实现和证据见[工作记录](../work_log/0218_vm2_foundation.md)及[验收回执](../reports/vm2_foundation_20261109/README.md)。
