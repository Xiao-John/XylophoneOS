# XylophoneOS Revival

x86-64独立OS：BIOS启动、NASM与受限C++微内核、用户态装载/文件/显示服务，提供原生
GCC/G++开发、FAT工作盘、xsh默认入口和可选dash。项目服务自己和朋友的开发与娱乐。

当前受限线程、Shell、ISO、显示、CPython与包管理能力及证据统一见[state](state.md)，
不在本页维护第二份通过清单；架构裁决见[宪法](xos_plan.md)，使用入口见[文档索引](README.md)。
0.0.1-1026已发布，后续源码不自动取得该发行资格；完整POSIX、Qt应用、SMP、UEFI与
系统重建/自举按独立阶段推进，不互相冒充。localpilot是独立项目。
