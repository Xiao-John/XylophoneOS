# XylophoneOS Revival version 0.0.1-1024

🎵 10.24，木琴开演。

XylophoneOS 的第一个正式纪念版本，送给一起玩 OSDev 的朋友们。

- 从 BIOS 启动，进入自己的 64 位操作系统。
- 多任务、进程隔离与用户态监督终端。
- FAT 工作盘、目录、文件编辑、保存与重启恢复。
- 在 XOS 里使用 GCC / G++ 和 GNU Binutils，编译并运行 C / C++ 程序。
- 独立 SDK，支持在宿主机上编译 XOS 应用。
- 串口里的小彩蛋，以及一个终于响起来的木琴。

## 下载与启动

下载 `xylophoneos_revival_0.0.1-1024_images.tar.gz`，解压后使用 Python 3 和 QEMU 启动：

```sh
python3 launch.py
```

在 `xos64>` 输入 `run`，进入 `sup>` 终端。工作盘已经装好编译器和示例源码：

```text
exec-driver /usr/bin/x86_64-elf-g++ -static --sysroot=/sysroot /src/hello.cpp -o /out/hello.elf
exec-file /out/hello.elf
```

SDK、对应源码与 SHA-256 校验清单随本次发行一同提供。

Happy 1024. Have fun with XOS!
