# XylophoneOS Revival version 0.0.1-1026

🎵 木琴继续响。

10.26，给一起玩 OS 的朋友们。

- 64 位系统、多任务、进程隔离与单核多线程。
- BIOS / QEMU 启动，install ISO 首次启动自动安装 dash；工作盘保持干净。
- Xshell 原生终端与 dash：流水线、子 Shell、命令替换、Here-document、exec 和 Make。
- FAT32 工作盘：目录、文件编辑、保存与重启恢复。
- XOS 内使用 GCC / G++、GNU Binutils 和 Make，编译并运行 C / C++。
- CPython 3.14：交互终端、线程、JSON、zlib / gzip / ZIP 和离线 Python 包。
- xypm 离线包管理，以及独立的 C / C++ SDK。

下载 images 包，安装 Python 3 和 QEMU 后运行：

```sh
python3 launch.py
```

在 `xos64>` 输入 `run` 进入 Xshell；输入 `dash -i` 或 `python3` 开始玩。
也可以直接编译示例：

```sh
exec-driver /usr/bin/x86_64-elf-g++ -static --sysroot=/sysroot /src/hello.cpp -o /out/hello.elf
exec-file /out/hello.elf
```

这是 BIOS/QEMU 的开发版；完整 POSIX、SMP、Qt 和 UEFI 仍未完成。Have fun!
