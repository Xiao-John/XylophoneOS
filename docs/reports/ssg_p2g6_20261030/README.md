# SSG P2G6 — scoped static Browser Gate B evidence

Base PR #10 HEAD fetched before work: `6ea0f6e3253754d075cedf4fcf7cff8596b2ca72`. The implementation reuses the existing collector, bounded retry loop, paging protocol and Diff. All final guest runs use the same final Consumer ELF and session ELF. The normal Browser ELF is used for the regressions, exhaustion and reload; a separately built diagnostic Browser from the same Browser sources is used for the Oracle runs. `browser-build-binding.json` and the receipts bind both binaries to source and distinguish the test-only flag. Oracle records are diagnostic serial output around existing page operations, not an IPC operation. Normal build has the Oracle flag off; its source guards and receipt were checked.

The new view can restart its numeric session counter: C was session 1 in a new epoch. It is not the old session; the identity is source instance + epoch + session. Old A is retained as historical data, not a current-document incremental baseline. Static replacement is not a same-document `TextChanged` event.

For the tested static liteHTML lifecycle (complete read, scroll/visibility/geometry change, bounded interruption and document replacement), Gate B is **PASSED_SCOPED**. Same-document runtime DOM editing is **UNSUPPORTED** by this Browser and was not simulated; complex identity changes, arbitrary HTML and timing, screen occlusion, production Broker, cross-process authorization and production security remain unqualified. No kernel, public ABI, QPA, driver, clock, scheduling, admission, authorization or resource-limit changes are claimed.

## Final-build regressions and evidence

- `diff-final`: real scroll 0→282, independent recomputation of 1 scroll, 219 window geometry and 90 visibility changes; 34 pages/267 nodes per baseline.
- `recover-final`: real single interruption after 3 pages, `STALE_CURSOR`, discard and full recovery; independent Diff recomputation passed.
- `pages-final`: original `browser-pages`, complete 34-page/267-node guest observation and clean children/resources. Its own qualification field is observation, not a DOM Oracle qualification.
- `p1-final-02`: affected guest Pipe suite PASSED_SCOPED, including real Notes interaction, denied text, malformed frames, timeouts and resource restoration to `[130297,2,0]`. This is a regression fixture only; no Notes branch changes were included.
- `structure-tests.log`: 52 P2F host validator tests passed. These supplement, not replace, the real Oracle runs.

Each `.tar.gz` preserves the full run directory: actual serial logs and JSON IPC payloads, input fixtures, QMP events with serial offsets, results, QEMU command, SHA-256 hashes and resource counts. Wire headers are reconstructed from protocol fields; payloads are exact Consumer logs. The independent check JSON files are also in the archives. Host verifiers are in `tests/ssg_p2g6_*_verify.py`. `consumer.receipt.json` records final build commands and hash; Browser receipts and build logs are included. Existing session and normal Browser binary/source bindings are unchanged from the fetched HEAD and checked through receipts. The guest reports include the exact QEMU command and binary/input hashes. `SHA256SUMS` covers delivered files.

`exhaust-run-01` used an earlier Consumer build and is retained as preliminary evidence only. `navigation-final` failed because its first test helper counted duplicate observations, and `navigation-final-02` failed from a harness NameError after the click; `navigation-final-03` passed but inherited inaccurate helper scope wording. All are preserved, and `navigation-final-04` is the final corrected test. The initial P1 output location failed before boot; `p1-final-02` is the final run. No historical frozen reports were changed.

For reproduction, invoke `tests/ssg_p2g6_exhaust_guest.py`, `tests/ssg_p2g6_reload_guest.py`, `tests/ssg_p2g5_guest.py` (Oracle A/B), and `tests/ssg_p2g6_navigation_guest.py --link-hit` with `--image`, `--session`, `--browser`, `--consumer`, `--input`, and a fresh `--output`; set `QEMU` to the recorded executable. Run the matching independent verifiers on each output directory. The standard regression scripts and their exact guest commands are captured in the reports. Runs require the matched XOS Qt SDK and image referenced in the receipts; these binaries are not claimed as a release.
