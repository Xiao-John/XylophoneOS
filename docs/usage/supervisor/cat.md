# `cat <file>`

- 控制台：用户态 supervisor
- 语法：`cat <file>`
- 实现：`src/user/services/file_ui.cpp`

读取整个文件并原样打印；若最后字节不是换行，补一个换行。
文件内容来自 FAT16 工作盘，不来自宿主路径。

失败返回真实错误，例如：

```text
[files] cat error=-1
```

`-1` 为 `not_found`，`-4` 为容量不足，`-5` 为 busy。读取不是逐行解析，
空行、连续空格和行尾空格都会保留。

限制：单文件 24 KiB；无分页/流式读取，`cat` 会一次性放入内部缓冲。
8.3 短名显示为大写，查找不区分大小写。
