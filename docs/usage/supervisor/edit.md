# `edit <file>`

- 控制台：用户态 supervisor
- 语法：`edit <file>`
- 实现：`src/user/services/file_ui.cpp`

进入原始行编辑模式。正文行不过命令分词器：

- 普通行原样追加，保留空行、连续空格、行尾空格；每行写一个 `\n`。
- 只有以 `:` 开头的行是编辑器命令：
  - `:w` 保存
  - `:wq` 保存并退出
  - `:q` 退出（有未保存修改时拒绝）
  - `:q!` 丢弃并退出
  - `:p` 打印当前缓冲
  - `:c` 清空缓冲
  - `:help`
- 保存使用文件服务的原子替换；空间不足/服务错误时保留编辑缓冲和旧文件，
  不会先截断旧文件。
- 缓冲上限 8 KiB；单行上限 159 字节；超长行拒绝但继续保留缓冲。
- 新文件显示 `(new)`，已有文件显示 `(loaded)` 和字节数。

限制：正文不能以 `:` 开头（当前无转义）；不是全屏编辑器，没有撤销/搜索；
没有目录/LFN，名字是 8.3 短名。
