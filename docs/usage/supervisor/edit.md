# `edit <file>`

用户态 Xshell 的行式文件编辑器，输入正文行时支持合法 UTF-8，文件内容按字节保存。
当前文件路径仍限 ASCII。载入上限 8192 字节，输入行上限 159 字节；超限拒绝，
不保存截断前缀。

- 普通行追加；以 `::` 开头可输入以 `:` 开头的正文。
- `:p` 打印正文；`:p N` 或 `:p N M` 显示有行号的行或闭区间。
- `:i N` 在指定行前插入，行数加一表示末尾；`:r N` 替换，`:d N` 删除。插入和
  替换命令后再输入一行正文。行号从 1 开始。
- `:w` 保存，`:wq` 保存成功后退出；`:q` 拒绝丢弃未保存修改，`:q!` 丢弃退出；
  `:c` 清空，`:help` 显示帮助。

以 LF 分行，未修改字节及末尾有无换行保留；显示控制字符和非法 UTF-8 字节时转义。
新输入须为合法 UTF-8，非法或超长行整行拒绝。保存失败保留缓冲并提示结果可能未知，
需要重新读取核对；不承诺多客户端冲突检测或任意断电安全。正常持久化仍需 `sync`。
该程序不是全屏编辑器，不提供搜索或撤销。
