# 0038：ISO 容量路线 A1（ISO9660 根目录与文件读取）

2026-10-25。用户在 A0 后要求继续 A1：最小 ISO9660 根目录查找，读出
`KERNEL.BIN` / `DASH.ELF`。本组只做独立探针，没有改现有 `xos.iso` 路径或
kernel 装载。

## 实现

- `scripts/make_iso.py`：新增 `--file NAME=PATH`，在 ISO 根目录写入文件记录和
  数据区；保留无文件时的原有行为。
- `tests/fixtures/cd_probe/iso_stage.asm`：
  - ATAPI PIO 逐扇区读取（每次重发 READ(10)，避免一次 PIO 跨扇区丢 DRQ）；
  - 读 PVD LBA16，取根目录 extent/size；
  - 遍历根目录记录，匹配 `KERNEL.BIN;1` / `DASH.ELF;1`；
  - 按记录里的 extent/size 读取，支持多扇区；
  - 校验首字节和末字节。
- `tests/cd_iso9660_probe.py`：生成含 2100 字节 KERNEL、5000 字节 DASH 的
  临时 ISO，QEMU `-cdrom` 启动并检查串口。

## 证据

- 串口：`A1 start` → `A1 ok KERNEL=2100 DASH=5000`。
- 报告 `build/cd_iso9660_report.json`：`passed=true`，ISO SHA256
  `06ac52c5c4d4e2c2dd9815d9fc63dd1eebfff71a9df14ed29b6cb4d77995dd49`。
- A0 回归仍通过：`tests/cd_atapi_probe.py`，`CDTEST ok: CD001`。

## 限制

- 只支持单层根目录、`;1` 文件名、单 extent、文件 <64 KiB；未实现路径表遍历、
  长名/Joliet、多 extent 和子目录。
- 只读文件到低内存缓冲区，尚未把 kernel 分块装到 1 MiB 以上；A2 才是解除
  640 KiB 对 kernel 的限制。
- 探针仍假设 secondary IDE master（0x170/0xA0）；真实硬件/其他固件未验证。
- 现有 `make run`/`xos.iso` 路径未改。
