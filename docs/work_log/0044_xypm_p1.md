2026-10-25。本组完成包管理器正式定名 **xypm**，并交付 P1 宿主候选盘事务与

## 定名

用户因撞名决定使用 xypm（C17）。当前命令、Python 模块/脚本、原生程序、
包 ID 和数据库目录统一为：

- 命令：`xypm`
- 包 ID：`xos.xypm`
- 原生程序：`/usr/bin/xypm`
- 数据库：`/var/lib/xypm/db.json`
- 查询投影：`/var/lib/xypm/index.tsv`（首行 `xypm-index-v1`）
- 脚本：`scripts/xypm.py`、`xypm_format.py`、`xypm_image.py`、
  `build_xypm.py`、`prepare_xypm_sdk.py`
- 宿主 FatFs 后端：`scripts/xypm_disk_host.cpp`

不保留 xpm/xpkg 可执行别名；`.xpk` 扩展名和 v1 容器/schema 不变。历史工作
记录、冻结 SDK 和已发布附件保留当时名称与哈希；旧名数据库/index 存在时
拒绝自动建立第二份归属库，没有静默迁移器。改名不代表商标或全球唯一性检索。

## P1 行为

宿主事务：

- 全会话排他锁；源盘只读复制到独立候选镜像，输出必须是尚不存在的新文件；
- install/upgrade/remove 先校验包、profile、依赖和文件归属，再修改候选盘；
- 升级按版本/revision/包 SHA256 精确匹配，不做范围求解或自动下载；
- 写完回读数据库和全部已归属文件，再通过同文件系统硬链接发布输出；
- 拒绝未归属文件覆盖、大小写/父路径/真实 FAT 别名冲突、已修改归属文件、
  破坏反向依赖的操作；保留卸载目录内用户文件，只清理本工具创建且已空的目录；
- 上限 64 包/8192 归属文件，数据库 1 MiB。

客体只读程序给 xsh 和 dash 同一 `list`/`info` 结果与退出码；不提供客体写入
事务。数据库写事务、恢复/并发留给 P2，仓库/签名留给 P3。

## 临时导出重名修复

验收中发现宿主导出临时文件可能重名，导致候选会话导出失败。修复后
`Disk.export()` 为每个会话使用 `uuid4().hex` 前缀并为每次导出递增 `serial`，
生成 `export_<prefix>_<serial>`；宿主导出端以 `fopen(..., "wbx")` 拒绝覆盖
已存在临时文件。失败样本保留在
`build/package_p1/xypm_acceptance/export_collision_failure.json`，修复后的
完整报告通过。
