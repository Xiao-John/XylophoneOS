真实 Xsh 探针在首个宽字符应用结束后通过 `stats` 记录空闲页、任务与未消费完成
记录；随后运行重入和 locale 应用，并在终端服务故障重启及再次运行 locale 后分别
比较三项是否回到同一基线。首个应用先预热文件和服务状态；该基线包含运行中的
终端服务，不代表终端停止后的资源，也不测瞬时峰值或所有资源类型。

此组只扩展宿主测试器，不更改系统实现。按要求在提交后基于干净快照构建并运行
组合 SDK 客体测试；结果待记录。多应用并发、长时间压力及完整 W1/W2 仍未验收。
