## 2. 选择与原因

- C4 采纳 #56 而非完成 scrub：改工作区字节撤不回已发布 git 对象（隐私收益有限），
  而全量改字节触发哈希级联——正是新契约禁止的结构；工具留档不删（C31：留真实
  记录，不假装未发生）。
- C5 从"改号"降级为"索引"：改号属历史重写，其级联会与守门扫描器形成螺旋
  （改动 → 暴露老清单的 open 面 → 又要改老清单 → 更大级联）；索引消歧以零
  历史改动恢复可追溯性，且把 8 组未登记撞号一并入册，覆盖面反而更完整。
- 账本入库：本债线多头并行（作者机线 + 本线），共享账本是最小协调成本。
