# Xsh 前台应用故障与准入探针

增加独立终端 opt-in 应用：输出就绪后访问受保护地址，预期以 page fault 退出。
真实 Xsh 客体探针在预热资源基线后，先以无 `.xos.tty` 标记的系统应用请求终端启动，
要求加载器拒绝；再启动故障应用，要求 Xsh 报告 vector 14、返回提示符且资源回到
基线。后续原有重启和再次运行检查仍保留。组合 SDK 消费者构建器新增该探针。

无标记系统应用的 ELF 已检查不含 `.xos.tty`；五个独立消费者已用整合后的组合 SDK
交叉链接。Python 编译通过；以上不是客体结果。提交后必须重建系统并运行真实客体。
该检查不涵盖 kill、fork/exec、其他应用并发或在途 I/O 的全部故障顺序。
