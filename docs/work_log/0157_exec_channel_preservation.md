# exec 显式保留通用通道

W1 前台 exec 需要同 PID 保留终端通道；现有 sys60 会关闭所有通道，直接放开 libc
exec 会破坏会话。新增通用显式扩展：调用方以 sys60 bit32 选择带最多四个 token 的
扩展 entry，内核在变更前检查身份、去重和空槽，成功仅保留列明端点；默认仍全部关闭，
失败不更改旧通道。该机制不解释终端；协议静默、在途响应和 sequence 仍由用户态负责。
具体边界见通道契约。SDK `spawn_options` 允许替换镜像时传入保留列表。

通道定向探针增加重复 token 导致 exec 失败后旧连接仍可通信，以及成功 exec 后同 PID
端点通信；普通系统 build `3bb3fe49a96182db` 和探针交叉编译通过，ABI 文档一致性
通过。客体未运行，必须先提交再重建执行；终端 libc 的 descriptor/sequence 交接、
fork、权限与并发压力仍未实现或未验证。原 W1/W2 资格不由此完成。
