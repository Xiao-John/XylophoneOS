# ncurses 宽字符非法输入及恢复

2026-11-03。已有 W2 验证覆盖 libc 的非法 UTF-8 转换，但未覆盖真实终端向
`wget_wch` 提供非法字节。锁定的 ncurses `lib_get_wch.c` 累积输入并尝试多字节
转换，遇到不能完成的序列不应假定立即报错或无损恢复；本轮先以有界读取实际验证。

宽屏客体在正常方向键、分片中文和 F1 之后设定一秒读取超时，通知宿主发送 `FF 41`，
要求读取返回 ERR；之后通知宿主另发 `B`，要求下一次宽字符读取成功且为 `B`。本例
验证无效前缀及其后已输入字节的有限超时与后续读取，不声称完整错误分类、任意截断
序列、键序列交错或无损保留 `A`。QEMU 驱动在正常 Xsh 和专用 supervisor 两种路径
均执行该握手；受限冻结工具新增此项为必需检查。提交之后须从匹配输入重新构建并
在客体运行，若行为与预期不同应记录失败并调查，不能只以交叉编译通过。
