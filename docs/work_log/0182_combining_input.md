# 组合字符输入探针

2026-11-03。W2 首版要求组合字符输入输出；现有宽屏消费者已经覆盖中文加 U+0301
的输出和 ncurses 单元读回，但输入只验证了分片中文。此轮在错误输入恢复后继续由
宿主发送 ASCII `a` 和 UTF-8 组合符 U+0301，并将组合符的两个字节分开发送；应用
要求两次 `wget_wch` 分别返回 `a` 和 U+0301。该检查覆盖码点输入及多字节分片，
不承诺字素簇合并、光标编辑或字体显示。

正常 Xsh 和专用 supervisor 的驱动均添加握手，受限冻结要求正常 Xsh 的对应检查。
提交后须从对应源码构建系统和消费者，并核对匹配 SDK、数据后运行客体；在实际通过
前不能把输出侧结果当作组合符输入已验证。
