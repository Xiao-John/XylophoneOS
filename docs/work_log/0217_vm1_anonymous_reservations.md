# VM1：稀疏匿名保留与解除

2026-11-09。基线 `0b121be`，分支 `codex/vm1-anonymous-reserve`。VM1在独立测试
镜像实现并验收；VM1–3尚未全部就绪，默认系统不开放sys67，不标记SDK能力，未改变
ABI登记或公开旧fork无法复制的保留区。

core固定容量的已排序区间集合按页处理16–32 TiB arena、每次4 TiB、累计8 TiB、
256片段与不超过1 TiB的幂次对齐。reserve支持hint回退和exact_nonreplace，unmap支持
洞、局部拆分和邻接合并。拆分额外槽不足时先拒绝，原数据和计数不变。无用户页或
页表分配；单CPU内核系统调用不在内核态调度，限定同一进程的修改串行。

`--vm1-probe`只允许隔离构建，启用测试专用67请求入口及专用物理空闲页回执；
保留区属于当前进程且退出释放。探针中保留区非空时fork/exec明确拒绝，直到VM3
实现相应语义；默认镜像无该入口或状态。请求指针复制后校验wire并返回契约错误，
info返回零能力位，未实现的操作拒绝。测试专用接口不是sys67的公共ABI分配。

最终探针构建 `77799411632cbddd` 在真实QEMU中完成大保留/配额、碎片、槽满回滚、
NONE读fault、进程退出及资源回收；默认构建 `9ebeaecdb6056692` 中有效请求被拒绝。
同一探针组合的dash C2 29项通过，包括真实fork内存不足回滚。
宿主20,000次确定性差分与ASan/UBSan通过，环境不支持LeakSanitizer。构建、系统和
探针摘要、串口、结果与局限见[回执](../reports/vm1_20261109/README.md)。初次构建
出现编译警告并修复；早期构建为纳入最终测试中止，不作为资格。文档/ABI一致性和
公开路径检查另执行。未执行VM2–VM3、完整V1/V3的commit/隐藏页部分、SMP或长期压力。

接续VM2：公开能力之前完成commit/protect/decommit、完整页表/回滚、pin与续体；
VM3再提供fork/exec及SDK兼容并通过V1–V7。不可把此测试入口等同已发布的匿名VM。
