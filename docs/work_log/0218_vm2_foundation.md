# VM2 有界续体与等待 pin 基底

2026-11-09，基线`a1dfa5f`，分支`codex/vm2-anonymous-pages`。按用户要求先完成
[简短基底规划](../plans/vm2_foundation.md)，VM2页面操作继续单独推进。

- 增加内核私有、按进程独占的续体状态：拥有者线程、全局单调代号、固定状态指针、
  准备/发布/回滚阶段及原失败结果。调度器每次调用的预算为32个工作单位；同进程
  其他线程在事务结束前不返回用户态，其他进程可运行。没有其他可运行进程时等待真实
  中断并使用已有统一时钟；不在内核栈保留跨调度局部状态。
- 准备中关闭/kill先进入分批回滚；发布中关闭/kill等发布步骤完成后再结束进程。
  子进程立即收到原有进程树取消；完成记录和资源回收在事务收口后处理。回调由内核
  可信调用方提供，须遵守32单位预算并在发布/回滚阶段保证不可恢复失败不会发生；
  回调上下文必须由有界内核事务对象持有。
- 显式记录线程异步用户范围pin：wait_word到唤醒/取消，join到写回/取消，process_wait
  到实际写回/取消。修复process_wait线程已就绪但尚未写回时旧检查不再视为pin的窗口。
  管道、显示、channel与IPC的当前等待只保存句柄/内核快照，用户缓冲在独立同步调用
  中访问；未来新增延迟访问时必须显式登记，不以现状推断未来协议安全。
- 现有`--vm1-probe`专用镜像增加模拟事务及pin观察探针，不分配公共ABI；探针最多分批
  分配和释放4096个用户页，模拟发布但不更改PTE。默认镜像不公开探针。
