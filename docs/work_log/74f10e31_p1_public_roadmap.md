had not advanced. GitHub now records the implementation and integration merges
through #417 and the separate pipe repair in #419. The next-round table also

preserved, relative links resolved, actual staged public-path scan, and review
that no production, test or build input changed. No runtime test is claimed by
this roadmap PR.
