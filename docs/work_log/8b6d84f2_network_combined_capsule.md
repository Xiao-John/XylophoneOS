## 可复核材料

[联合 summary](../reports/p0_network_combined_20261128/summary.json) 给出两种
系统的独立身份、全部命令、工具和边界；
[DHCP guest](../reports/p0_network_combined_20261128/dhcp_guest.json) 与
[TLS guest](../reports/p0_network_combined_20261128/guest.json) 为本次实际回执。
三份客体串口、构建与输入回执保留在同一平铺目录。原始 DHCP pcap、完整逐帧
解码和详细只读审查仅保留本地，公开材料只含原件摘要、协议计数与测试结论，
不能据此声称公众能重新检查原始抓包。目录外的
[转换记录](../evidence_exports/p0_network_combined_20261128.json) 区分实际公开的
规范化副本和未公开的本地原件。报告根 manifest 仅绑定实际公开的叶子。

原始抓包的 create_blob 公开上传被自动审批拒绝；在完整检查测试来源与全部
197 帧内容后，同一操作仍被拒绝，理由是缺少对该抓包网络元数据的明确披露授权。
因此从尚未发布的候选树中移除二进制和完整解码，也不以另一种编码公开等价内容。
[公开范围说明](../reports/p0_network_combined_20261128/README.md) 记录这一边界。
本次修改只缩小公开范围，没有改变客体执行、原始文件或实测结果。

所有流量来自受控测试 peer/服务端；不发布私钥或 CA PEM/DER bundle。
这项组合回归分别验证 DHCP 安装 profile 与静态开发网络上的 TLS，没有验证
DHCP profile 上的 TLS、公网浏览器策略、物理 NIC、可信物理时间、硬件熵、
并发 PSA、完整 Qt 消费者或 R1 发行冻结/接收者重链接材料。后者仍由独立实物门承担。
